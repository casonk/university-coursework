# PM Templates

Project management document templates sourced from CSC580-Advanced_Software_Engineering.

The full collection (65 files) lives at:

```
CSC580-Advanced_Software_Engineering/PM_Templates/
```

## Contents

Templates cover the full PM lifecycle:

- **Initiation**: charter, business case, potential project, stakeholder register
- **Planning**: project management plan, scope statement, WBS, milestone list, schedule, RACI chart, communication plan, risk register, quality management plan, requirements traceability matrix
- **Execution/Monitoring**: performance report, issue log, change request, earned value chart, burn-down chart
- **Closure**: lessons-learned report, customer acceptance form, contract closure notice

## Formats

`.doc` / `.docx` — Word documents
`.xls` / `.xlsx` — Excel spreadsheets
`.ppt` — PowerPoint (cause/effect diagram, org chart, probability-impact matrix)
`.mpp` — MS Project (project schedule)
